# Industrial Production Data Warehouse

> An end-to-end Data Engineering project for transforming raw industrial production data into an analytical Data Warehouse using SQL, Google BigQuery, Medallion Architecture and dimensional modeling.

---

## Introduction

This project simulates the development of a modern Data Warehouse for an industrial manufacturing environment.

The source systems provide raw CSV files containing production records, product information, packaging specifications, production shifts and supervisor information.

The goal is to transform these heterogeneous raw datasets into a reliable analytical data platform that can be used to monitor production performance and support business intelligence.

The project follows a **Medallion Architecture**:

# Project Overview

The project simulates an industrial production environment where several operational datasets are generated by different source processes.

## Source Datasets
* **Production / MES data**
* **Product master data**
* **Packaging information**
* **Production shift information**
* **Supervisor production information**

---

# Project Requirements

The solution must:

- **Ingest** the provided production CSV files.
- **Store** raw data in the **Bronze** layer.
- **Clean and standardize** data in the **Silver** layer.
- **Apply** data quality rules.
- **Integrate** the operational datasets.
- **Build** a dimensional model.
- **Create** a **Gold** analytical layer.
- **Calculate** production KPIs.
- **Provide** data suitable for BI consumption.
